# ساخت APK پالپ بدون نصب Android Studio (با GitHub Actions)

نیازی به SDK و Gradle روی کامپیوتر شما نیست. فقط مرورگر با VPN.

## ۱) آدرس سایت را در پروژه بگذارید
پوشه‌ی `pulp-android` را از zip اکسترکت کنید. فایل زیر را با Notepad باز کنید:

`app\src\main\res\values\strings.xml`

مقدار `site_url` را به آدرس سایت خودتان تغییر بدهید (با `/` در انتها)، مثلاً `http://آدرس-شما/pulp/`. ذخیره کنید.

## ۲) ساخت مخزن (Repository) در GitHub
1. در مرورگر (با VPN) وارد github.com شوید و حساب رایگان بسازید.
2. بالا سمت راست `+ ← New repository`. نام: `pulp-android`. گزینه‌ی **Public**. `Create repository`.

## ۳) آپلود فایل‌ها
1. در صفحه‌ی مخزن روی لینک **uploading an existing file** بزنید.
2. **محتوای** پوشه‌ی `pulp-android` را (نه خود پوشه را) با ماوس بکشید و داخل صفحه رها کنید: یعنی پوشه‌ی `app`، پوشه‌ی `gradle`، و فایل‌های `build.gradle` و `settings.gradle` و `gradle.properties`.
3. پایین صفحه `Commit changes`.

## ۴) فایل ساخت خودکار
اگر پوشه‌ی مخفی `.github` آپلود نشد (ممکن است در ویندوز دیده نشود):
1. در صفحه‌ی مخزن `Add file ← Create new file`.
2. در کادر اسم دقیقاً بنویسید: `.github/workflows/build-apk.yml` (وقتی `/` می‌زنید پوشه ساخته می‌شود).
3. محتوای فایل `build-apk.yml` (همراه همین پروژه) را داخل کادر بزرگ کپی کنید. `Commit changes`.

## ۵) ساخت و دانلود APK
1. تب **Actions** را باز کنید. اگر پرسید «workflows را فعال کنیم؟» گزینه‌ی سبز را بزنید.
2. از ستون چپ **Build APK** را انتخاب کنید ← دکمه‌ی **Run workflow** ← دوباره **Run workflow**.
3. ۵ تا ۱۰ دقیقه صبر کنید تا تیک سبز بیاید. (ممکن است بعد از Commit خودش هم شروع شده باشد.)
4. روی همان اجرا کلیک کنید. پایین صفحه بخش **Artifacts** ← `Pulp-APK` را دانلود کنید.
5. zip دانلودی را اکسترکت کنید؛ داخلش `app-debug.apk` است. همان را نصب کنید یا برای دوستانتان بفرستید.

## اگر اجرا قرمز شد (Failed)
روی اجرا کلیک کنید، مرحله‌ی قرمز را باز کنید و آخرین چند خط خطا را برای من بفرستید.

## نکات
- مخزن Public است؛ فقط کد پوسته‌ی برنامه و آدرس سایت داخلش است (که خودتان برای کاربران منتشر کرده‌اید).
- هر وقت آدرس سایت عوض شد، `strings.xml` را در GitHub ویرایش کنید (آیکن مداد) و دوباره Run workflow بزنید.
- اگر GitHub دسترسی حسابتان را محدود کرد (بعضی حساب‌ها از ایران محدود می‌شوند)، بگویید تا راه دیگری بدهم.
