# پالپ — پروژه‌ی اندروید (Android Studio)

یک پوسته‌ی سبک (WebView) که سایت پالپ شما را مثل یک برنامه نمایش می‌دهد. سایت هر بار از همان آدرس بارگذاری می‌شود، پس با هر به‌روزرسانی سایت، برنامه هم خودکار به‌روز است و نیازی به ساخت APK جدید نیست.

## ساخت APK
1. **Android Studio** را نصب کنید (رایگان): https://developer.android.com/studio
2. `File > Open` و همین پوشه (`pulp-android`) را باز کنید. بار اول چند دقیقه طول می‌کشد تا ابزارها دانلود شوند.
   اگر پیشنهاد «Upgrade Gradle/AGP» آمد، قبول کنید.
3. فایل `app/src/main/res/values/strings.xml` را باز کنید و مقدار **site_url** را به آدرس سایت خودتان تغییر دهید (حتماً با `/` در انتها). مثلاً `http://mysite.com/pulp/` (آدرس‌های http بدون SSL هم کار می‌کنند)
4. از منو: `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
   فایل نهایی: `app/build/outputs/apk/debug/app-debug.apk`
5. این فایل را برای دوستانتان بفرستید یا روی سایت بگذارید. موقع نصب، اندروید می‌پرسد «نصب از منبع ناشناخته» را اجازه می‌دهید؟ بله.

## نسخه‌ی امضاشده (release)
برای انتشار جدی‌تر (مثلاً بازار/مایکت): `Build > Generate Signed Bundle / APK`، یک keystore بسازید و **آن را جایی امن نگه دارید** (برای به‌روزرسانی‌های بعدی لازم است).

## امکانات
- انتخاب عکس/ویدیو/فایل از گوشی برای ارسال
- «ذخیره در گالری» عکس‌ها و ویدیوها (پوشه‌ی Pulp داخل Pictures و Movies) و ذخیره‌ی فایل‌ها در Downloads
- دکمه‌ی بازگشت: اول بستن پنجره یا چت باز، بعد خروج
- صفحه‌ی «بدون اتصال» با دکمه‌ی تلاش دوباره
- لینک‌های بیرونی در مرورگر باز می‌شوند

## تغییر نام یا آیکن
- نام برنامه: `strings.xml` ← `app_name`
- آیکن: فایل‌های `app/src/main/res/mipmap-*/ic_launcher.png`
- شناسه‌ی برنامه (Package): `app/build.gradle` ← `applicationId`

> این پروژه در محیط ساخت من کامپایل نشده (Android SDK در دسترس نبود)، ولی از قالب استاندارد WebView استفاده می‌کند. اگر Android Studio خطایی نشان داد، متنش را بفرستید.
